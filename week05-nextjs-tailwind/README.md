# Week 5 - Next.js and Tailwind CSS

A responsive, server-rendered studio landing page built with the Next.js App Router and Tailwind CSS.

## Requirements demonstrated

- App Router layout, route and static export
- Server-rendered page with a small client boundary only for the contact form
- Metadata, `next/link` navigation and `next/image` image handling
- Responsive Tailwind utility styling
- `loading.tsx` and `error.tsx` route boundaries

## Run locally

```bash
npm install
npm run dev
```

Build the static GitHub Pages version with `npm run build`. The export is written to `out/`.
