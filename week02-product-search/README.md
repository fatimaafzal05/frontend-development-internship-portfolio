# Week 02 - Product Search Page

A framework-free JavaScript product search page built for Week 2 of the internship.

## Concepts demonstrated

- ES modules with `import` / `export`
- `async` / `await`, `fetch`, `try` / `catch`, and an error state
- Dynamic DOM rendering from the DummyJSON public API
- Arrays and objects with `map`, `filter`, `Set`, spread syntax, and destructuring
- Search filtering, category filtering, sorting, loading, and empty states

## Run locally

Open `index.html` with a local server (for example, VS Code Live Server). The public API requires an internet connection.

## Files

- `index.html` — semantic page structure
- `style.css` — responsive styling
- `app.js` — UI state, filtering, sorting, and DOM rendering
- `api.js` — public API request module
