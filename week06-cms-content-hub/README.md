# Week 6 - CMS Content, Motion and Accessibility

An editorial content hub built with Next.js, TypeScript, Tailwind CSS and Framer Motion.

## Skills demonstrated

- CMS-style content model separated from the UI layer
- Server-rendered content with an interactive client-side category filter
- Responsive Tailwind layouts and accessible, labelled controls
- Framer Motion entrance transitions that honour `prefers-reduced-motion`
- Metadata, optimized images, loading and error boundaries

## Run locally

```bash
npm install
npm run dev
```

Run `npm run build` to generate the static site in `out/` for GitHub Pages.
