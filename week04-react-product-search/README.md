# Week 04 - React + TypeScript Product Search

The Week 2 search page rebuilt as a React application with TypeScript.

## Reusable component library

- `Button` - typed appearance and native button props
- `Badge` - composable category label
- `Input` - typed controlled search input
- `ProductCard` - typed product display component

The app uses `useState` for UI state, `useEffect` for the one required API fetch, `useMemo` for derived filtering/sorting, controlled form inputs, conditional rendering, and keyed lists.

## Build

```bash
npm run build:week04
```
