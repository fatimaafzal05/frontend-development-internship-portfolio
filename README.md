# Frontend Development Portfolio

A selection of responsive web projects built while learning modern frontend development. The repository covers HTML, CSS, JavaScript, TypeScript, React and Next.js.

## Projects

- Responsive Landing Page - HTML and CSS
- Product Search - JavaScript and TypeScript
- React Product Search - React and TypeScript
- Studio Landing Page - Next.js and Tailwind CSS
- Content Hub - Next.js, Tailwind CSS and accessible interactions
